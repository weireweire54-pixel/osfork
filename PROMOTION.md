## Short post

I built osfork, a tiny experimental 32-bit x86 kernel that boots in QEMU. It has a keyboard-driven shell, a small persistent virtual filesystem, a local text-page viewer, and tic-tac-toe. It is an educational project, not a general-purpose OS, and it has not been tested on physical hardware.

Repository: https://github.com/weireweire54-pixel/osfork

I would especially appreciate feedback on the setup instructions, shell usability, and beginner-friendly kernel tasks.

## Project update

**osfork v0.1.0 QEMU preview is out.** This is my learning project for exploring x86 kernel development. It currently boots in QEMU and includes a small shell, persistent filesystem snapshots, a text-only built-in page viewer, and tic-tac-toe. The README has Windows setup instructions and the repository is MIT-licensed.

Try it or review the code: https://github.com/weireweire54-pixel/osfork

Known limits: experimental kernel, QEMU-focused, no networking or general-purpose filesystem, and no physical hardware validation. Feedback and small contributions are welcome.
