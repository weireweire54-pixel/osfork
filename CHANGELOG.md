# Changelog

## v0.1.0 - QEMU Preview

- Boot a 32-bit x86 Multiboot kernel in QEMU.
- Show a VGA text-mode terminal and accept keyboard input.
- Provide a small interactive shell and in-memory filesystem.
- Save filesystem snapshots to a dedicated QEMU IDE disk image.
- Include a local text-page viewer and tic-tac-toe.
- Document the experimental status and current hardware limitations.
